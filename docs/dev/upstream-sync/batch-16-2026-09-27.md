### 跨 owner 与双空间保持的边界

- 当前 `StepRunner` 仍在成功 receipt 后调用 `ToolOutputCompactionPlanner.planAfterSuccessfulRequest`，由 `ToolOutputStore.stageCompaction` 返回替换与 lease，随 ModelResponseCheckpoint 或 FinalizeTurn 提交。阈值仅来自 ContextBudget。P02 多行输出、P03 opaque replay、P06 UI 折叠不能新增裁剪 writer 或改动前缀策略。

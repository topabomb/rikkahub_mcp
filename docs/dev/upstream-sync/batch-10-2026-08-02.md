### 2.3 `952fa019` — fix(android): declare legacy storage permission

| 项目 | 内容 |
|------|------|
| **类别** | bug 修复（兼容性） |
| **优先级** | P1 |
| **判定** | ✅ 同步 |

**问题**：Android 8.0-9.0（API 26-28）设备上，`WRITE_EXTERNAL_STORAGE` 权限未声明，导致部分文件写入操作失败。

**上游改动**：
```xml
<uses-permission
    android:name="android.permission.WRITE_EXTERNAL_STORAGE"
    android:maxSdkVersion="28" />
```

**本地核对**：本地 `AndroidManifest.xml` 确认未声明此权限。当前权限列表：INTERNET、ACCESS_NETWORK_STATE、CAMERA、RECORD_AUDIO、POST_NOTIFICATIONS、POST_PROMOTED_NOTIFICATIONS、ACCESS_WIFI_STATE、CHANGE_WIFI_MULTICAST_STATE、FOREGROUND_SERVICE、FOREGROUND_SERVICE_SPECIAL_USE、ACCESS_LOCAL_NETWORK、PACKAGE_USAGE_STATS、READ_CALENDAR、WRITE_CALENDAR。→ **确认需要同步**

**价值评估**：⭐⭐⭐ — 本地 `minSdk = 26`，`targetSdk = 37`。在 API 26-28 设备上，`WRITE_EXTERNAL_STORAGE` 是写入公共目录（Downloads 等）的必要权限。本地备份导出、文件导出等功能在这些设备上可能失败。`maxSdkVersion="28"` 确保不影响 API 29+ 设备的 scoped storage 行为。

**合理性**：✅ 合理。标准兼容性修复，`maxSdkVersion` 限制范围，无副作用。

**完整性**：✅ 无遗漏。

**持久化影响**：无。`maxSdkVersion="28"` 限制只在 API ≤ 28 生效，不影响高版本设备。

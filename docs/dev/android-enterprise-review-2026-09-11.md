## 修复

| 问题 | 修复及回归 |
| --- | --- |
| 读取中登录到期仍返回动态 | Portal 列表/详情和 Gateway 列表在存储读取后复验原授权；扩展已有 Feed 到期测试，覆盖各实际读取入口 |
| 历史、分页和统计只在查询开始检查授权 | 原 query owner 返回结果前复验，保留工具的原 Session 与页面的原选择；新增可控时钟反例，修复前均失败 |
| 文件目录及清理计数/删除影响读取同样遗漏返回前复验 | 复用 Session 校验；上传与图库计数分别覆盖读取中到期，不改变文件删除协议 |
| 旧空间错误残留、迟到同步失败进入新空间 | EnterpriseVM 将错误绑定原选择，同步反馈校验原空间；竞态测试覆盖离开与返回 |
| WebView 在导航回调内同步销毁 | 全量设备门禁在重载用例触发 Chromium 原生崩溃；授权立即撤销，物理清理由原宿主在回调返回后执行，原回执覆盖移除、销毁及站点数据清理 |
| 长动态编辑页关闭/刷新随内容滚出 | 使用有固定操作区的 AlertDialog，正文滚动并避让软键盘；编辑期间禁止刷新覆盖草稿，长按钮可换行 |
| MCP 不可用说明挤压名称与开关 | 将说明纳入名称所在的弹性列，保持开关可达 |
| 共享定义确认时原页面失效直接抛异常 | 沿原操作失败反馈处理，取消仍传播 |
| 个人/企业识别与文字不够清楚 | 空间入口和当前空间卡增加少量人物/企业图标，保留名称与模拟标识；五语言优化接入资料、企业参考记忆和动态操作说明 |
